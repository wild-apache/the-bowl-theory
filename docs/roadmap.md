# Roadmap

## Phase 0 — Repository foundation
- [x] Establish project scope and monorepo layout.
- [x] Document architecture, security boundaries, and milestones.
- [ ] Choose final framework versions and package manager.
- [ ] Add CI checks and baseline formatting/linting.

## Phase 1 — Customer storefront
- [ ] Mobile-first home page and brand presentation.
- [ ] Menu categories and product cards.
- [ ] Pack-size options and clear pricing.
- [ ] Contact, social, and delivery-platform links via environment configuration.
- [ ] Accessible navigation, SEO metadata, and basic analytics consent review.

## Phase 2 — Kitchen admin
- [ ] Staff authentication and role-based access.
- [ ] Menu/product availability management.
- [ ] Order board with explicit status transitions.
- [ ] Preparation and packing checklist.

## Phase 3 — Business tools
- [ ] Ingredient and packaging cost sheets.
- [ ] Pack-level costing and margin calculator.
- [ ] Inventory and reorder thresholds.
- [ ] Sales and channel-fee reporting.
- [ ] Exportable reports with access controls.

## Phase 4 — Production readiness
- [ ] Automated tests and CI.
- [ ] Backups, monitoring, and error reporting.
- [ ] Privacy policy and customer-data retention rules if customer data is collected.
- [ ] Deployment configuration and rollback procedure.
- [ ] Validate all external integrations in a test environment.

## Release criteria

A phase is complete only when its acceptance criteria, security checks, and basic tests are documented and verified. Roadmap items are planned work, not implemented features.
